## Validation snapshot

Fresh clean Vulkan-enabled and no-Vulkan Debug builds passed CTest; the Vulkan run used the available llvmpipe Vulkan CPU implementation and included valid/malformed GGUF and SafeTensors fixtures, indexed model descriptors, exact native GGUF Q4_0/Q8_0/Q4_K payload bounds, model-bound lazy caller-buffer Q4_0/Q8_0/Q4_K execution helpers, model-backed dense graph binding, strict native MLP and attention profile shape/type/scratch checks, CPU/Vulkan model-bound MLP-to-logits and attention/KV differentials, multi-layer transformer execution with per-layer KV caches on a two-layer GQA fixture, exact GGUF vocabulary parsing and tokenizer tests, bounded native prompt-to-text generation with deterministic sampling and stop handling, CLI generation argument coverage, backend-selecting model-native Q8_0 matvec, file-span bounds, the narrow dense graph-plan fixture, the tiny decoder golden-logit fixture, explicit Mixtral mapping, selected-expert F32 and native Q4_K CPU MLP fixtures, model-bound rank-3 Q4_K selected-expert span staging against the CPU oracle, the MoE oracle, quantized tensor contracts, generic scalar/DP4/Q4_K/Q8_0 dispatch, native Q4_K/Q8_0 Vulkan/CPU differential dot and one-command multi-row matvec fixtures, and bounded KV payload COW/read/write/rollback/reuse tests. All generated shader modules contained compute entry points; named no-Vulkan stubs also passed. Implementation source measured 404,396 bytes after GQA attention, SafeTensors F32 MLP/logits execution, strict architecture binding, Vulkan-first runtime additions, model-bound MoE staging, and all-layer CLI validation. Discrete-GPU behavior/performance remains unvalidated; arbitrary architecture variants, full tokenizer semantics, server, batching, and streaming remain incomplete. Cooperative matrices remain absent from implementation paths.
